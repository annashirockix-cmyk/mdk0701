# Обновлённые данные лекций для локального учебного сайта

## Состав
- `data-0201.js` — МДК 02.01
- `data-0202.js` — МДК 02.02
- `data-0401.js` — МДК 04.01
- `data-0701.js` — МДК 07.01
- `lecture-methodical.css` — дополнительное оформление новых методических блоков

## Что добавлено
Для тем добавлены цель, планируемые результаты («знать/уметь»), теоретическое пояснение, алгоритм, ключевые термины, практическое задание, самопроверка и итог. Продолжительность темы задана как 60 минут. Сохранены исходные ключи `window.MDK_DATA`, идентификаторы и существующие поля данных, чтобы не ломать совместимость с интерфейсом. Для МДК 07.01 добавлены темы, которые есть в рабочей программе, но отсутствовали в исходном JS.

## Подключение
1. Сделайте резервную копию исходных файлов.
2. Замените одноимённые JS-файлы в проекте файлами из архива.
3. Если нужно дополнительное оформление, добавьте `lecture-methodical.css` в HTML после основного CSS:
   `<link rel="stylesheet" href="lecture-methodical.css">`
   Либо скопируйте его содержимое в конец существующего `style.css`.
4. Откройте сайт локально и проверьте все вкладки и карточки тем.

## Важно
Теоретические блоки расширяют исходные данные учебными пояснениями и не заменяют официальную рабочую программу. Численные режимы резания, допуски и настройки конкретного оборудования необходимо брать из чертежа, паспортов станков и методических указаний преподавателя.
