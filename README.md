# МДК 07.01 — портал оператора станков с ПУ

Статический сайт: лекции, практика, самопроверка и тесты по рабочей программе ПМ.07 (профессия 16045).

## Запуск

Откройте `index.html` или поднимите любой статический сервер из корня репозитория.

## Папки

- `img` — схемы и фоны
- `pasport` — PDF паспортов станков
- `ohranatruda` — инструкции по охране труда
- `video` — ролики. Файлы `.mp4` в архив для GitHub не входят: GitHub не принимает файлы больше 100 МБ. Положите их в `video/` с именами `1.mp4` … `9.mp4` (без `7.mp4`).
- `Code.gs` — бэкенд Google Apps Script. ID таблицы уже указан. После вставки кода опубликуйте новую версию веб-приложения.

Адрес веб-приложения задаётся в `api.js` (`APPS_SCRIPT_URL`).
